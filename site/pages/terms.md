## 1. 内容与版权

本站展示的标题、摘要、精读与关注理由由模型根据公开来源生成，**可能有误**。涉及漏洞的一切技术判断（编号、受影响版本、利用状态、修复版本）请以厂商通告、CVE/NVD/GHSA/CNVD 等原始来源为准。

原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。本站是聚合摘要与阅读索引，不托管原文全文。

## 2. 本站不提供什么

- **不托管、不分发可执行的漏洞利用代码**。公开的 PoC 仓库、检测模板只以外部链接和事实描述的形式出现在情报里。
- 不提供任何目标探测、批量扫描、攻击托管或"代打"服务。
- 站内出现的漏洞信息**不构成对任何系统的测试授权**。对未取得书面授权的目标进行测试可能构成违法，责任由行为人自负。
- 不提供漏洞赏金、期刊发表、求职等中介服务。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页或上面的邮箱联系我们，我们会在 **7 个工作日内**处理。涉及仍在修复中的敏感细节，我们会优先下架。

## 4. 使用本站的数据

**无需另行申请即可使用**：

- 个人阅读，以及组织内部的安全运营与应急响应；
- 教学、研究与媒体引用，需注明本站名称并链回原页面；
- 个人或组织内部把 RSS、公开 API、MCP 接进自己的聚合阅读器或 Agent 做只读使用。

**需要事先取得书面同意**：

- 把本站内容（含摘要、精读、红蓝视角）嵌进对外销售的商业产品或服务；
- 公开转载超过 200 字的摘要或整段精读、红蓝视角；
- 批量抓取、长期镜像或对外提供本站数据的二次接口；
- 用于训练模型、构建数据集，或用于任何形式的模型蒸馏。

**禁止**：

- 用于对任何目标进行未授权的测试、扫描或攻击；
- 删除、隐藏或篡改来源标注与免责声明后再传播；
- 用于违反中华人民共和国法律法规的用途。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。**请勿用本站接口做漏洞目标的批量探测或资产测绘。**

本站按"现状"提供，不保证内容完整、准确和持续可用。**漏报、误报以及据此做出的处置决定，本站不承担责任**；请结合自身资产情况与官方通告判断。

本站可能随时调整信源、精选口径与功能，也可能在提前公告后停止服务。
